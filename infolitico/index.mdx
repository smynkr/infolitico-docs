Infolitico is a faith-framed news site. Its daily-news lane reports a real,
source-backed event, then offers a spiritual reflection and prayer. A curated
Bible verse appears only when the selector recommends one.

<Warning>
  The default source implements an automated daily-news pipeline, from
  source-event admission through publication, without human editorial writers
  in that lane. A separate owner-gated script can publish a hand-authored
  Inspirational Thought article; repository code does not establish which
  publishing lanes are currently running in production.
</Warning>
